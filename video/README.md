## التعديل وإعادة الإنتاج

- `index.html`: الفيديو كاملًا (رسوم SVG وحركات وتوقيتات). افتحيه في المتصفح لمعاينة تفاعلية
  فيها زر تشغيل وشريط تقديم. النصوص كلها في بداية كل مشهد، وبيانات المحطات في المصفوفة `ST`.
- `audio.py`: يولّد الموسيقى الخلفية والمؤثرات الصوتية برمجيًا (من دون ملفات خارجية أو حقوق).
- `render.cjs`: يحوّل الصفحة إلى MP4 مع الصوت:

```bash
cd video
NODE_PATH=$(npm root -g) node render.cjs 3 30   # 3 عمليات متوازية، 30 إطارًا/ث
```

المتطلبات: Node مع Playwright (Chromium)، وPython 3 مع numpy، وffmpeg.
الخطوط: Cairo وTajawal (رخصة OFL) موجودة في `fonts/`.
