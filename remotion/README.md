# فيديو «لغز المختبر: الصفحات المفقودة» (مبني بـ Remotion)

فيديو احترافي 1920×1080 بمعدل 30 إطارًا في الثانية (نحو ٢:٥٩ دقيقة)، مبني على سيناريوهات ملف
«المرحلة الثانية: بناء مخطط المنتج والتفاعل»، ومصمَّم بأداة [Remotion](https://www.remotion.dev) (React).

- **الناتج:** `out/lab-mystery-missing-pages.mp4`
- **اللقطات الحقيقية:** كل مشهد له خانة لمقطع مصوَّر حقيقي في `src/footage.ts`.
  تفاصيل ما يُصوَّر في [SHOT_LIST.md](SHOT_LIST.md). وما دامت الخانة فارغة يظهر المشهد المرسوم مكانها.

## النسخة التفاعلية (الطالبة هي التي تختار)

في المجلد `interactive/`. تعمل بمشغّل Remotion الرسمي (`@remotion/player`): تُشغَّل المشاهد كفيديو،
وعند كل قرار يتوقف الفيديو وتظهر الخيارات أزرارًا حقيقية تختار منها الطالبة بنفسها، واختيارها يحدد المشهد التالي.

| الخطوة | ما تفعله الطالبة |
|--------|------------------|
| البداية والمهمة | تشاهد المشرفة ثم تضغط «ابدئي التحقيق» |
| دفتر السلامة | تختار أي محطة تريد، وبأي ترتيب |
| العدسة | تنقر بنفسها على ما يبدو غير سليم في المشهد (٣ قرائن)، وفي المحطة ٤ تنقر العبوة فتظهر العدسة على الملصق |
| إعادة الشريط | تضغط لتشاهد ما فعلته سلمى، ويتوقف الفيديو عند اللحظة الحرجة |
| القرار | تظهر ٣ خيارات تختار منها. الخطأ يشغّل مشهد «لنرَ ما سيحدث…» مع تلميح، ثم «أعيدي المحاولة»، والصحيح يشغّل «قرار موفّق!» وعودة الصفحة إلى الدفتر |
| دفتري | تكمل كل قانون باختيار الكلمة المناسبة |
| الكشف الختامي | تشاهد الكشف، وتكتب إجابتها عن «ماذا كنتِ ستفعلين في مكان سلمى؟»، ثم الختام |

```bash
npm run app         # تشغيل محلي للتجربة
npm run build:app   # موقع ثابت جاهز للنشر في out/interactive
```

## اللقطات الحقيقية المستخدمة

لقطات حقيقية مجانية من [Mixkit](https://mixkit.co) (رخصة Mixkit المجانية، ولا تُشترط الإشارة إلى المصدر).
**كلها للممثلة نفسها** (سلسلة Mixkit من 21452 إلى 21461) لتكون «سلمى» شخصية واحدة في جميع المشاهد، ولا رجال فيها.
والرسم البديل لسلمى في مشاهد الأخطاء مصمَّم ليشبهها: شعر داكن مربوط وزيّ مختبر بنفسجي.

| الخانة | أين تظهر | رقم المقطع في Mixkit |
|--------|----------|---------------------|
| `mission` | المهمة: تبحث في المختبر | 21457 |
| `st1_right` | بعد القرار الصحيح في المحطة ١: تفحص الأنبوب بالقفازات | 21454 |
| `st2_right` | بعد القرار الصحيح في المحطة ٢: تعمل بهدوء على المجهر | 21452 |
| `st3_right` | بعد القرار الصحيح في المحطة ٣: يدان جافتان بقفازات | 21460 |
| `st4_right` | بعد القرار الصحيح في المحطة ٤: تفحص العيّنة عن قرب | 21455 |
| `st5_right` | بعد القرار الصحيح في المحطة ٥: تتعامل مع الأنابيب بحذر | 21453 |
| `ending` | الختام: تنظر من المجهر ثم تبتسم | 21459 |

مشاهد الأخطاء نفسها ما زالت مرسومة، إذ لا توجد لقطات مجانية لها. تُستبدل بتصويركن متى توفرت، حسب `SHOT_LIST.md`.

## الأوامر

```bash
cd remotion
npm install
npm run studio          # معاينة وتعديل تفاعلي في المتصفح (Remotion Studio)
npm run render          # تصدير MP4 إلى out/
npm run audio           # إعادة توليد الموسيقى والمؤثرات (يتطلب Python 3 وnumpy)
```

إذا تعذّر على Remotion تنزيل متصفحه، فاستخدمي متصفح Chrome أو Chromium مثبّتًا على الجهاز:
`REMOTION_CHROME=/path/to/chrome npm run render`
