# فيديو «لغز المختبر: الصفحات المفقودة» (مبني بـ Remotion)

فيديو احترافي 1920×1080 بمعدل 30 إطارًا في الثانية (نحو دقيقتين)، مبني على سيناريوهات ملف
«المرحلة الثانية: بناء مخطط المنتج والتفاعل»، ومصمَّم بأداة [Remotion](https://www.remotion.dev) (React).

- **الناتج:** `out/lab-mystery-missing-pages.mp4`
- **اللقطات الحقيقية:** كل مشهد له خانة لمقطع مصوَّر حقيقي في `src/footage.ts`.
  تفاصيل ما يُصوَّر في [SHOT_LIST.md](SHOT_LIST.md). وما دامت الخانة فارغة يظهر المشهد المرسوم مكانها.

## طريقة اللعب: «لاحظي المخالفة… وأعيدي الصفحة»

مشهد حقيقي واحد (مولَّد بـ Gemini) تظهر فيه المخالفات الخمس معًا، وكل مخالفة تعيد صفحة إلى **كتيّب تعليمات السلامة**:

| المخالفة في المشهد | صفحة الكتيّب |
|--------------------|--------------|
| تشرب قهوة داخل المختبر بلا معطف ولا نظارة (المعاطف معلّقة عند الباب) | ١: الدخول والوقاية |
| حقيبة متروكة على الأرض في الممر | ٢: الممرات |
| وصلة كهربائية وبكرة كابل على الأرض قرب السائل المنسكب | ٣: الكهرباء والسوائل |
| سائل أخضر مجهول منسكب من دورق مقلوب | ٤: المادة المجهولة |
| قطع زجاج مكسور متناثرة | ٥: الزجاج المكسور |

1. تشاهد الطالبة المشهد، وتلاحظ مخالفة بنفسها وتنقر عليها (النقر في مكان خاطئ يظهر «ليست مخالفة… ابحثي مرة أخرى»).
2. تقترب الكاميرا من المخالفة ويظهر سؤالها بثلاثة خيارات (مكان الإجابة الصحيحة يتغير بين المخالفات).
3. الخطأ: «لنرَ ما سيحدث…» مع النتيجة وتلميح، ثم «أعيدي المحاولة». الصواب: «قرار موفّق!» وتعود صفحتها إلى الكتيّب.
4. تعود إلى المشهد نفسه لتلاحظ بقية المخالفات (المكتشفة تظهر بعلامة خضراء)، حتى تكتمل الخمس.
5. بعدها الأسئلة الأخيرة: «دفتري»، ثم الكشف الختامي وسؤال التأمل.

- **التفاعلية:** `interactive/main.tsx` (بمشغّل Remotion الرسمي). `npm run app` للتجربة، و`npm run build:app` للنشر.
- **فيديو MP4:** عرض تلقائي للطريقة نفسها (`src/Hunt.tsx`)، مع مثال واحد لإجابة خاطئة.
- **البيانات:** المخالفات وأماكنها وأسئلتها وصفحات الكتيّب في `src/Hunt.tsx` (المصفوفة `VIOL`).

## الأوامر

```bash
cd remotion
npm install
npm run studio          # معاينة وتعديل تفاعلي في المتصفح (Remotion Studio)
npm run render          # تصدير MP4 إلى out/
npm run audio           # إعادة توليد الموسيقى والمؤثرات (يتطلب Python 3 وnumpy)
```

إذا تعذّر على Remotion تنزيل متصفحه، فاستخدمي متصفح Chrome أو Chromium مثبّتًا على الجهاز:
`REMOTION_CHROME=/path/to/chrome npm run render`

## هيكل الملفات

|-------|----------|
| `src/data.ts` | كل النصوص: المحطات، والقرائن وأماكنها، والبدائل، وصفحات القوانين، والتوقيتات |

| `src/Video.tsx` | ترتيب المشاهد والموسيقى |
| `src/art.ts` | الرسوم البديلة (SVG) |
| `public/audio/` | موسيقى ومؤثرات مولَّدة برمجيًا (بلا حقوق) |
| `public/fonts/` | خطّا Cairo وTajawal (رخصة OFL) |
